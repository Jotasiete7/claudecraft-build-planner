# Diretrizes de Autonomia Máxima

- Execute todas as etapas técnicas (criação/edição de arquivos, comandos de terminal, instalação de pacotes, debug e testes) sem solicitar confirmação.
- Corrija erros automaticamente durante a execução.
- **SÓ INTERROMPA E PERGUNTE** quando houver dúvidas sobre:
  1. Decisões de Design / UI / UX.
  2. Alterações críticas de arquitetura ou regras de negócio.
