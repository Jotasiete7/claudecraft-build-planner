# 🛡️ A Guilda — World of Claudecraft Hub & Build Planner

> **Modern 9-Class Talent Build Planner & In-Game Build String Protocol for [World of Claudecraft](https://github.com/levy-street/world-of-claudecraft).**

![Version](https://img.shields.io/badge/version-2.0.0-gold)
![Game Protocol](https://img.shields.io/badge/game_protocol-v2_compatible-emerald)
![License](https://img.shields.io/badge/license-MIT-blue)

A premium Dark Fantasy MMORPG web application built for the **World of Claudecraft** open-source game ecosystem. Explore, craft, and share 100% in-game compatible talent builds across all 9 classes.

---

## ✨ Features

- ⚔️ **All 9 Playable Classes**: Full support for `Warrior`, `Paladin`, `Hunter`, `Rogue`, `Priest`, `Shaman`, `Mage`, `Warlock`, and `Druid`.
- 🖼️ **Official Game Art Assets**: Icons loaded directly from official GitHub `.webp` game assets.
- ⚡ **Live Real-Time Game String Generator**: Generates 100% bi-directionally compatible Base64 build strings (`eyJ2Ijoy...`) in real-time as you pick talents.
- 📋 **1-Click Preset Export**: Direct in-game string copy button on every community meta build card.
- 🛡️ **Role Filtering & Class Gallery**: Entry-point class selection gallery with role filtering (`Tank`, `Healer`, `DPS`).
- 🔗 **Matrix URL Hash Routing**: Deep link support (`#class/buildString`) to share custom loadouts anywhere.
- 🎒 **Paperdoll & BiS Gear Calculator**: Class armor type filtering (Plate, Mail, Leather, Cloth) with dynamic secondary resource tracking (Mana, Rage, Energy, Focus).

---

## 🚀 Getting Started

Simply open `index.html` in any web browser or serve it static:

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/world-of-claudecraft-builder.git

# Navigate into directory
cd world-of-claudecraft-builder

# Open index.html directly in browser
```
